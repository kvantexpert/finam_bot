# План приведения finam_bot в порядок

## Этап 1 — выполнен

- убрать из Git runtime-артефакты;
- привести `.gitignore` к реальному Python-проекту;
- зафиксировать текущую и целевую структуру;
- не менять торговую логику.

## Этап 2 — структура кода

- перенести собственный код в `src/finam_bot/`;
- оставить `FinamPy/` только как отдельную vendored-зависимость либо заменить её на нормальную зависимость;
- убрать дублирование `arbitrage_trader.py` и `arbitrage_finder.py` после миграции;
- оставить совместимые CLI-обёртки на переходный период.

## Этап 3 — торговая модель

- описать реальные инструменты Finam;
- построить треугольники только из существующих рыночных отношений;
- убрать магические коэффициенты лотов;
- учитывать tick size, lot size, комиссии и проскальзывание.

## Этап 4 — execution и risk

- разделить signal / risk / order plan / execution / fill / position / unwind;
- обработать partial fills;
- реализовать настоящий unwind исполненной позиции;
- добавить лимиты риска и circuit breaker;
- paper mode сделать безопасным режимом по умолчанию.

## Этап 5 — тесты

- unit-тесты математики;
- mock-тесты заявок и fills;
- тесты аварийного unwind;
- smoke-test подключения к Finam без размещения заявок.

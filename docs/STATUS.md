## Важное состояние

### Можно

- развивать новую структуру в `src/finam_bot/`;
- писать offline unit-тесты;
- исследовать Finam instruments;
- проектировать новую модель арбитражных циклов;
- создавать fake/mock execution для тестов.

### Нельзя пока

- включать live-торговлю через старый арбитражный код;
- считать новый `execution` готовым;
- переносить старую triangle math без проверки реального рынка;
- удалять `core/` целиком, пока остаются его зависимости.
